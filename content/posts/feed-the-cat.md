## Feed the Cat

I stumbled upon this website while discovering the indieweb. It is a website that has different rooms with different cats. In each room there is a timer for you to feed the cat, which triggers the machine to drop a few kibbles.

It is cute and calming to watch, and you have to be patient to see the cats.
